# PRD: 伴语 (Banyu) v2

> 主动式 AI 陪伴产品。一个有性格的虚拟角色，会主动来找你聊，提供情绪支持。
> v2 升级：语音电话 + 角色形象/声音自定义 + 二次元 UI 重做。

---

## 1. 需求清单

### 1.1 流式聊天对话 [P0]（已有，保留）
- **功能描述**：用户与角色实时对话，LLM 流式输出回复，消息历史持久化
- **验收标准**：
  - 成功路径：用户发送消息 -> 后端流式调用 LLM -> SSE 逐 token 推送前端 -> 打字效果渲染 -> 消息落库
  - 失败路径：LLM 调用失败 -> 显示"角色暂时走神了，稍后再试" -> 用户消息不丢失
  - 边界条件：空消息不发送；超长消息(>4000 字)截断并提示
  - 性能：首 token <1.5s，完整回复 <30s

### 1.2 语音电话 [P0]（新增，替换原 1.5 语音对话）
- **功能描述**：两种语音交互模式，用户不打字，全程语音对话
- **模式 A - 连续语音模式**：
  - 用户按住说话 -> ASR 识别 -> 自动发送 -> LLM 回复 -> TTS 播放 -> 继续按住说话
  - 适合：碎片化对话，不想打字
- **模式 B - 实时通话模式**：
  - 点击"电话"按钮进入通话界面 -> VAD 自动检测说话开始/结束 -> ASR -> LLM -> TTS 连续播放
  - 通话界面显示角色立绘 + 通话时长 + 挂断按钮
  - 适合：沉浸式长对话，像打电话
- **验收标准**：
  - 成功路径（连续模式）：按住 -> 录音 -> 松开 -> ASR -> LLM 流式回复 -> TTS 播放 -> 可继续
  - 成功路径（实时通话）：点击电话 -> 进入通话界面 -> 说话自动识别 -> 角色语音回复 -> 挂断退出
  - 失败路径：ASR 识别失败 -> "没听清，再说一次"；TTS 不可用 -> 仅文字；网络中断 -> 提示重连
  - 边界条件：浏览器不支持 Web Speech -> 隐藏语音按钮；录音 ≤60s；通话中不接收其他消息
  - 声音克隆已配置时，TTS 用克隆声音；未配置时用浏览器默认声音
- **优先级**：P0

### 1.3 角色形象与声音 [P0]（新增，升级原 1.3 角色系统）
- **功能描述**：用户创建角色时上传图片作为角色形象（立绘/头像），上传语音样本做声音克隆
- **图片上传**：
  - 上传图片作为角色头像 + 角色详情页大图展示（立绘模式）
  - 支持裁剪/缩放
  - 对话页顶部显示角色头像，通话界面显示角色大图
- **声音克隆**：
  - 用户上传 5-15 秒语音样本
  - 后端调用语音克隆服务训练声音模型
  - 训练完成后，TTS 用该声音说话
  - 未上传语音时，使用浏览器内置 TTS（默认女声）
- **验收标准**：
  - 成功路径（图片）：上传图片 -> 预览裁剪 -> 保存 -> 角色卡片/对话页/通话页显示该图片
  - 成功路径（声音）：上传语音 -> 后端训练 -> 状态变为"已克隆" -> 对话 TTS 使用该声音
  - 失败路径：图片格式不支持 -> "请上传 JPG/PNG/WebP"；图片 >5MB -> 压缩或拒绝；声音训练失败 -> "声音克隆失败，使用默认声音"
  - 边界条件：图片 ≤5MB；语音 5-15 秒；支持 JPG/PNG/WebP；支持 WAV/MP3；声音克隆需 30s-2min
- **优先级**：P0

### 1.4 主动式陪伴 [P0]（已有，保留）
- **功能描述**：角色定时主动发消息 + 事件触发主动关心，通过 Web Push 推送
- **验收标准**：
  - 成功路径：定时任务触发 -> 生成主动消息 -> Web Push + 应用内消息
  - 失败路径：推送不可达 -> 应用内展示；LLM 失败 -> 兜底文案
  - 边界条件：夜间不推送；同日 ≤3 条
- **优先级**：P0

### 1.5 长期记忆 [P0]（已有，保留）
- **功能描述**：检索用户关键信息注入对话上下文，角色能记住用户的事
- **验收标准**：
  - 成功路径：用户提及关键信息 -> 提取存储 -> 后续对话检索注入 -> 角色引用
  - 失败路径：检索失败 -> 降级无记忆对话
  - 边界条件：top-5；可查看/删除
- **优先级**：P0

### 1.6 模型列表过滤 [P1]（新增）
- **功能描述**：`/llm/models/{provider}` 只返回有效的对话类模型，过滤掉 embedding/vision/image/tts 等
- **验收标准**：
  - 成功路径：请求模型列表 -> 后端过滤 -> 只返回对话模型（含 chat/instruct/completion 关键词）
  - 过滤规则：排除 embedding/vision/image/tts/asr/whisper/clip/multimodal 等非对话模型
  - 边界条件：过滤后列表为空 -> 提示"该 provider 暂无可用对话模型"
- **优先级**：P1

### 1.7 心情日记 [P1]（已有，保留）
- **功能描述**：用户记录每天心情，角色基于日记主动陪伴
- **验收标准**：
  - 成功路径：写日记 -> 保存 -> 提取关键信息入记忆
  - 边界条件：≤1000 字；可设私密
- **优先级**：P1

### 1.8 情绪识别触发 [P1]（已有，保留）
- **功能描述**：LLM 分析情绪，负面情绪触发角色主动关心
- **验收标准**：
  - 成功路径：负面得分 >阈值 -> 触发主动关心
  - 边界条件：同会话 ≤1 次；阈值可调
- **优先级**：P1

## 2. 视觉/页面框架（v2 重做）

### 设计方向：二次元/虚拟角色风格
- **参考网站**：
  1. 星野（角色立绘/黑金暗调/沉浸氛围）
  2. Replika（治愈气质/对话先行/语音入口）
- **参考截图**：
  - `references/design/reference-v2/01-xingye-home.png` - 星野首页（黑金暗调/角色立绘/卡片网格）
  - `references/design/reference-v2/03-replika-home.png` - Replika 首页（极简/暖橙/对话气泡）
- **设计要素提取**：
  - 星野：深黑底(#050505) + 暖金强调(#F0C958)、无框大立绘展示、背景角色卡片网格、中心亮四周暗渐变暗角、圆角胶囊按钮+细金描边
  - Replika：白底+暖橙强调、对话先行半隐藏角色、大量留白松弛治愈、语音/通话入口在对话页核心操作区
- **核心气质**：沉浸式角色陪伴，角色形象是视觉中心，不是工具型聊天界面
- **配色方案**：
  - 主背景：深色/暗色底（#1a1a2e / #16213e）营造沉浸感
  - 强调色：暖粉/暖紫（#e8a0bf / #c084fc）+ 柔光金（#fbbf24）
  - 文字：白色/浅灰（#f0f0f0 / #a0a0b0）
  - 卡片：半透明毛玻璃（rgba(255,255,255,0.08) + backdrop-blur）
- **导航结构**：底部 tab（对话 / 角色 / 日记 / 我的）+ 全屏沉浸式对话/通话

### 页面布局

#### 对话页
- 顶部：角色头像（圆形）+ 角色名 + 在线状态 + 语音电话按钮
- 消息流：角色消息左侧（带头像），用户消息右侧，圆角气泡
- 底部输入栏：文字输入 / 按住说话 / 语音电话按钮 切换
- 背景：暗色 + 微妙的渐变/粒子效果

#### 通话页（新增）
- 全屏角色立绘/大图（背景虚化）
- 顶部：通话时长
- 中间：角色头像/立绘 + 语音波形动画
- 底部：挂断按钮（红色）+ 静音按钮
- 说话时角色头像有呼吸光效

#### 角色页
- 角色卡片：大图 + 名字 + 人设简介 + "开始对话"按钮
- 横向轮播或竖向列表
- 创建/编辑：图片上传 + 语音上传 + 人设编辑

#### 设置页
- API key 配置 / 模型选择（过滤后）
- 通知开关 / 记忆管理
- 暗色风格

### 移动端优先
- 所有页面按移动端 390px 宽度设计
- 触控友好：按钮 ≥44px，输入框 ≥48px 高
- 安全区适配（notch/home indicator）
- 不像网页：无大段留白，信息密度高，交互元素明显

## 3. 项目边界
- [x] **上线公开**（做能用的产品，面向用户）
- [x] **用户数据**：账号 / 对话 / 日记 / API key / 上传的图片和语音 -> 需隐私合规；MVP 无支付
- [x] **性能与成本**：首 token <1.5s；用户自带 LLM API key；声音克隆依赖第三方 TTS 服务
- [x] **本地优先**：不用云服务器，本地运行 SQLite + 本地文件存储

---

## 4. 技术栈（v2 调整）
| 层 | 选型 |
|----|------|
| 前端 | Next.js 16 (App Router) + TS + Tailwind 4 + Zustand + PWA |
| 后端 | FastAPI (Python) + SQLAlchemy async + aiosqlite |
| LLM | 多 Provider 适配层（OpenAI/豆包/火山Coding/通义/DeepSeek/智谱），模型列表过滤 |
| 语音 ASR | Web Speech API（浏览器内置） |
| 语音 TTS | Web Speech API（默认）+ 火山引擎 TTS（声音克隆，需额外配置） |
| 文件存储 | 本地文件系统（uploads/ 目录） |
| 实时通话 | WebSocket（FastAPI）+ VAD（语音活动检测） |
| 数据库 | SQLite（开发）-> Postgres（生产） |
| 主动陪伴 | APScheduler + Web Push |
